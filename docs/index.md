# GeoTile Label

GeoTile Label jest desktopową aplikacją do przygotowywania datasetów uczenia
maszynowego na podstawie zobrazowań satelitarnych i lotniczych. Zachowuje georeferencję, metadane źródłowe oraz pochodzenie adnotacji.

## Główna zasada

```text
pełne sceny + metadane + adnotacje źródłowe = źródło prawdy
kafelki + splity + formaty ML = produkty pochodne
```

Oryginalne dane wejściowe pozostają tylko do odczytu. GeoTile Label zapisuje
projekty, adnotacje i regenerowalne produkty pochodne w lokalizacji projektu.
